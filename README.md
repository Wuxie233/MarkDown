## 开发原则

- 先定义玩家流程、状态与失败路径，再组织命令模块。
- 用稳定接口连接主体与拓展，避免跨系统直接修改内部状态。
- 控制每 tick 的命令执行量，并为多人数据做隔离和清理。
- 功能发布后继续记录版本、修复问题并维护兼容性。
